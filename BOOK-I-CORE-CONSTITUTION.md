# BOOK I — THE AMEXAN CORE CONSTITUTION

## Version 1.0

**The Supreme Constitution of the AMEXAN Clinical Operating System**

**Status:** Immutable · **Editor:** AMEXAN Clinical OS · **License:** Proprietary — AMEXAN Internal

---

## PREAMBLE

We believe healthcare is a continuously evolving human system that should never be limited by software.

AMEXAN exists to become the constitutional operating system upon which healthcare organizations, clinicians, patients, researchers, educators, governments, humanitarian organizations, and future healthcare innovations can safely operate.

The Constitution exists to guarantee:

- safety
- interoperability
- scalability
- adaptability
- explainability
- sustainability
- longevity

**No implementation shall supersede the Constitution.**
**Every module shall conform to the Constitution.**
**Every future technology shall extend—not replace—the Constitution.**

## VOLUME ONE — PHILOSOPHY

The operating system shall never be built around pages. It shall be built around healthcare.

Healthcare consists of:

```
People
Organizations
Knowledge
Reasoning
Care
Communication
Education
Research
Improvement
```

Everything else is implementation.

**Constitutional Principles**

1. Healthcare is dynamic. Software must therefore be dynamic.
2. Medicine changes. The Constitution must survive changing medicine. Protocols are therefore data, not code.
3. Hospitals differ. The Constitution must remain identical. Customization occurs outside it.
4. The user never learns software. Software learns the user.
5. Clinical reasoning is sacred. No interface shall alter clinical reasoning.
6. The Constitution never contains implementation.
7. Everything is represented as objects, not screens.
8. Every object owns Identity, Lifecycle, Relationships, Permissions, Version, Telemetry. Always.
9. Every interaction must be explainable.
10. Every decision must be auditable.
11. No AI may bypass constitutional reasoning.
12. Presentation never owns logic.
13. Logic never owns presentation.
14. Everything must be replaceable.
15. Everything must be reusable.
16. Everything must be measurable.
17. Every module must be testable independently.
18. Every organization owns its data. AMEXAN provides the operating system.
19. No hospital may customize constitutional behaviour. Only configurable behaviour.
20. Backward compatibility is constitutional. Never break previous hospitals.

## CONSTITUTIONAL OATH

Every developer contributing to AMEXAN should follow this:

> *I shall never place business logic where presentation belongs. I shall never compromise patient safety for convenience. I shall never hardcode what should be configurable. I shall preserve the Constitution above implementation. I shall build systems that remain understandable, extensible, testable, explainable, and safe for future generations of healthcare.*

## IMPLEMENTATION REFERENCE

The enforceable machine-readable form of this document lives at:

```
lib/amexan/constitution/books/book-I-core-constitution.ts
```

It exports `CORE_CONSTITUTION_VERSION`, the constitutional principles, domains, objects, relationships, engines, lifecycles, rules, security principles, versioning rules, extension points, dependency pyramid, golden rules, the oath, and conformance helpers (`assertObjectConstitutional`, `assertExtensionConforms`, etc.).

From this point onward we stop inventing architecture. Every future feature must answer:

> Which constitutional object, engine, relationship, lifecycle, and rule does it belong to?

If it cannot answer that question, it does not enter the codebase.
